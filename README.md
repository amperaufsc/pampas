# Pampas

## Suggested description for issue "Software architecture"

Define and document a high-level software architecture for Pampas, clarifying the
responsibilities and integration boundaries of each module (`amp_bringup`,
`amp_mapping`, `amp_motion`, `amp_perception`, and `amp_utils`) and how they
connect to the main application entrypoint.

The goal is to provide a shared technical reference that guides future
development, helps keep modules cohesive and decoupled, and makes onboarding and
maintenance easier.
